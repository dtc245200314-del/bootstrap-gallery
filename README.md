# Gallery Bootstrap — hoạt động 448

Mở `index.html` bằng trình duyệt. Bốn ảnh SVG nguyên gốc dùng cùng class `col-12 col-sm-6 col-lg-3`: một cột điện thoại, hai cột tablet, bốn cột desktop. Ảnh có alt, kích thước và liên kết mở bản đầy đủ; img-fluid giữ tỉ lệ.

Bootstrap 5.3.8 (MIT) qua CDN có SRI, theo https://getbootstrap.com/docs/5.3/ . Trang mẫu CodeGym được đề dẫn không truy cập được bằng công cụ tra cứu; giao diện triển khai theo yêu cầu lưới rõ ràng của bài. Mã và tranh tự triển khai với trợ giúp Codex.
